# Nika Estate landing pages

- Repository: https://github.com/anisimovkat-hub/nika-estate
- Live base URL: https://anisimovkat-hub.github.io/nika-estate/
- Deployment: GitHub Pages, `main` branch, repository root
- Build: static HTML, CSS and JavaScript; no package installation

## Routes

- `/` — City Walk + Central Park
- `/dubai/` — UAE property selection with a six-step quiz and project examples
- `/uae/` — Dubai and Abu Dhabi comparison
- `/saudi-arabia/` — Saudi Arabia / Riyadh / OSUS Eye
- `/invest-meeting/` — online investment consultation

## Lead routing

The Dubai page has two lead paths: a six-step selection quiz and a short broker consultation form. Both open the official Nika Estate WhatsApp number `+971 50 869 8020` with a prefilled message. The visitor reviews and sends the message in WhatsApp.

## Content safeguards

Prices, unit availability, views, handover dates and payment plans are described as subject to confirmation. Rows marked for verification in the client registry are not published as current numeric offers.
